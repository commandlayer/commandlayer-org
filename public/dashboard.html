What gets published

Primitives, not an authority score.

A marketplace, wallet, registry, buyer, or analyst can apply its own weighting without treating CommandLayer as the final judge.

Attributable activity

Paid executions, outcomes, settlement totals, distinct payer keys, and execution IDs remain traceable to a service version and manifest hash.

Anti-self-dealing signal

Related-party activity is counted only when supported by explicit evidence. Repetition alone does not prove collusion.

Evidence coverage

Consumers can see how many executions carry evidence references instead of mistaking volume for quality.

Identity layer

Names can multiply. Authority stays singular.

An agent may have an HTTPS endpoint, ENS name, ERC-8004 identity, marketplace listing, and wallet. Each adapter should resolve back to the same canonical service ID, manifest hash, and receipt identity.
